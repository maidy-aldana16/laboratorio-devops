01 / Fundamentos

Tres herramientas.
Un mismo objetivo.

Construir aplicaciones reproducibles, mantener servicios disponibles y automatizar su entrega mediante buenas prácticas DevOps.

01 — CONTENEDORES

Docker

Empaqueta el sitio web dentro de una imagen Nginx para ejecutarlo de forma consistente y comprobar su respuesta HTTP.

02 — ORQUESTACIÓN

Kubernetes

Administra pods, escala un Deployment a tres réplicas y reemplaza automáticamente una instancia eliminada.

03 — AUTOMATIZACIÓN

GitHub Actions

Valida archivos, construye y prueba el contenedor Docker, y publica el HTML estático mediante GitHub Pages.

02 / Integración y despliegue

Del commit a la web.

Un cambio en main activa un flujo automatizado que se detiene si alguna comprobación falla.

STEP / 01

Push a GitHub

El repositorio recibe una nueva versión del código.

STEP / 02

Validación

Se verifica la existencia y el contenido del sitio web.

STEP / 03

Prueba Docker

Nginx inicia en un contenedor y responde a una solicitud HTTP.

STEP / 04

GitHub Pages

Si las pruebas aprueban, se despliega el sitio HTML estático.
